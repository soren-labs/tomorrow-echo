# 明日回声 · Tomorrow Echo

把今天的预测寄给明天的自己。

例如：「明天我会在 23:00 前睡觉，信心 80%。」提交后预测不可修改，到期记录结果，看看自己的信心与现实相差多少。

这是一个用于评估 Devin **API 默认 SWE-2 Max** 完整交付能力与额度消耗的小型全栈项目。当前仓库是开发任务的起点，应用尚未实现。

## MVP

- 邮箱、密码注册登录和退出；真实会话与数据库。
- 写下预测、信心概率和揭晓时间；封存后不可修改。
- 到期后选择「发生了 / 没发生」，可写一句复盘；只能结算一次。
- 查看自己的封存中、待揭晓、已结算卡片和平均预测得分。
- 提供 1 分钟揭晓选项，让真实部署可以快速验收。

技术方案：Next.js App Router + TypeScript + Tailwind，Better Auth 邮箱密码认证，Drizzle + Neon Postgres，部署到 Vercel。一个应用、一张业务表，加认证库自带表。首版不接大模型 API，使用者操作不会混入模型费用。
